# Le Dernier Train de Minuit

Jeu d'aventure à choix multiples, créé uniquement avec HTML et CSS.

## Pour lancer le jeu

1. Décompresse le dossier.
2. Ouvre `index.html` dans ton navigateur.
3. Clique sur les boutons pour choisir la suite de l'histoire.

## Organisation

- `index.html` : début de l'aventure.
- `pages/scene01.html` à `pages/scene19.html` : les 19 autres pages.
- `style.css` : un seul fichier CSS pour les 20 pages.
- `assets/backgrounds/` : 7 illustrations de décor au format SVG.
- `assets/icons/` : petites icônes des boutons au format SVG.
- `arbre-navigation.pdf` : carte des liens et des cinq fins.

## Ce qui a été simplifié

- Aucune ligne de JavaScript, aucun framework.
- Même scénario, mêmes choix et cinq fins que la version originale.
- Pages HTML courtes avec des balises classiques : header, nav, main, section, h1, p, a, footer.
- Styles regroupés dans un CSS commun, avec des commentaires simples.

## Rendu

Le PDF d'arbre de navigation correspond aux liens de cette version. Dépose le dossier complet dans ton dépôt Git.
